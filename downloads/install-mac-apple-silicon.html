Install MELETRA 4.1.2 on an Apple Silicon Mac

For M1, M2, M3 and M4 Macs. This build currently requires macOS 26 or newer. For a Mac whose processor says Intel, use the Intel download.

  1. Open the Apple Silicon release and download both files ending in .part001 and .part002 into Downloads.
  2. Open Terminal, paste the following command and press Enter. GitHub requires the 3.2 GB disk image to be supplied in two parts; this joins them:
cd ~/Downloads && cat MELETRA-Apple-Silicon-Mac-Offline.dmg.part001 MELETRA-Apple-Silicon-Mac-Offline.dmg.part002 > MELETRA-Apple-Silicon-Mac-Offline.dmg
  1. Double-click MELETRA-Apple-Silicon-Mac-Offline.dmg, then drag MELETRA to Applications.
  2. In Applications, right-click MELETRA, choose Open, then choose Open again. The app is verified by the project but is not notarized by Apple yet; do not disable Gatekeeper for the whole Mac.

The Apple Silicon-optimized Whisper Large-v3 MLX model is already included. After installation, transcription works offline and no model download is needed.

Uninstall

Drag MELETRA from Applications to the Trash. Your saved transcripts and settings are not removed automatically.
