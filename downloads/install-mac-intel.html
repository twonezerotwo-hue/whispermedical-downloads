Install MELETRA 4.1.2 on an Intel Mac

For Intel Macs only, macOS 12 or newer. Apple menu → About This Mac must say Intel. For M1/M2/M3/M4 use the Apple Silicon download.

  1. Open the Intel Mac release and download both files ending in .part001 and .part002 into Downloads.
  2. Open Terminal, paste the following command and press Enter. GitHub requires the 3.1 GB disk image to be supplied in two parts; this joins them:
cd ~/Downloads && cat MELETRA-Intel-Mac-Offline.dmg.part001 MELETRA-Intel-Mac-Offline.dmg.part002 > MELETRA-Intel-Mac-Offline.dmg
  1. Double-click MELETRA-Intel-Mac-Offline.dmg, then drag MELETRA to Applications.
  2. In Applications, right-click MELETRA, choose Open, then choose Open again. The app is verified by the project but is not notarized by Apple yet; do not disable Gatekeeper for the whole Mac.

Whisper Large-v3 is already included. After installation, transcription works offline and no model download is needed.

Uninstall

Drag MELETRA from Applications to the Trash. Your saved transcripts and settings are not removed automatically.
