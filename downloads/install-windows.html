Install on Windows

Windows 10/11, 64-bit. About 3.6 GB are downloaded during installation and about 8 GB of free disk space are needed.

  1. On the download page click Download for Windows. A small file, WhisperMedical-Installer-Windows.exe, is saved.
  2. Double-click it. If Windows shows “Windows protected your PC”, choose More info, then Run anyway. (The installer is not code-signed yet; this screen appears for every new unsigned program.)
  3. Click Install. The installer downloads the program and the Whisper Large-v3 speech model, checks every file automatically and refuses to install anything that does not match.
  4. When Windows asks whether the installer may make changes, choose Yes. The normal WhisperMedical setup runs.
  5. WhisperMedical starts. The speech model is already in place — nothing is downloaded when you open it.

If your internet connection drops, close the installer and start it again: it continues where it stopped and does not download everything again.

Uninstall

Settings → Apps → Medical Lecture Transcriber → Uninstall. Your transcripts and models are kept.
